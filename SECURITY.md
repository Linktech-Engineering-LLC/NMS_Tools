## 1. Supported Versions

NMS_Tools is actively maintained and security‑patched on a best‑effort basis.
The following versions currently receive security updates:

| **Version** | **Supported** |
| *---* | *--- |
| 2.x | ✔ Supported |
| 1.x | ✘ Not supported |
| 0.x | ✘ Not supported |

Older versions may continue to function, but they do not receive security fixes.

## 2. Reporting a Vulnerability

If you discover a security vulnerability in NMS_Tools, please report it privately.

**Contact:**  
ldmcclatchey@linktechengineering.net

Please include:

* A clear description of the issue  
* Steps to reproduce (if applicable)  
* Any relevant logs or environment details  
* Your assessment of potential impact  

You will receive an acknowledgment within **72 hours**, and updates will be provided as the issue is investigated.

If the vulnerability is confirmed:

* A fix will be developed as quickly as possible  
* A security advisory will be published (if appropriate)  
* Credit will be given to the reporter unless anonymity is requested

Please do **not** disclose the vulnerability publicly until a fix has been released.

Thank you for helping keep NMS_Tools secure.
