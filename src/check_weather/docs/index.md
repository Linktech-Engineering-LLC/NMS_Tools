## 1. Overview

check_weather is the backend engine used by the weather CGI script and the web demo.
It performs:
* provider queries
* data normalization
* forecast slicing
* structured output generation

Earlier versions included icon classification and recoloring, but these subsystems have been moved into **PythonTools/weather_icons** and are no longer part of the runtime pipeline.

This index links to all documentation relevant to development, maintenance, and integration.

## 3. Related Components
### 3.1 Weather Icons Classification & Recolor Engine (PythonTools)
The icon classification and recoloring engine now resides in:

```Code
PythonTools/weather_icons/
```

This subsystem includes:
* `analyzer.py` — geometry + filename hybrid classifier
* `recolor.py` — palette application and SVG rewriting
* `export_icons.py` — batch processor and stats generator

These components are **no longer part of the check_weather directory.**
`check_weather` does not perform recoloring at runtime.

See **Classification.md** for the classification model, and
**PythonTools/weather_icons/README.md** for the recoloring pipeline.

## 3.2 Weather Demo (Web UI)
Documentation for the web UI lives in:

```Code
web/docs/
```

The demo uses recolored icons generated by PythonTools, but
`check_weather` itself does not perform recoloring.

## 4. Pipeline Overview

```Code
provider query
→ normalization
→ forecast slicing
→ output (JSON / verbose / quiet / Nagios)
```

Icon classification and recoloring are part of the **asset generation pipeline** in PythonTools,
not the runtime pipeline of `check_weather`.
